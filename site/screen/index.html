How to read this reconstruction

This is an approximate reconstruction from JavaScript readings, not a capture of the browser’s actual UI. The outer-to-inner height difference combines tab bars, address bars, bookmark bars, info bars, borders, docked tools or other non-page areas. It cannot tell which ones are present or how the total is distributed.

Screen minus window size is not proof of a taskbar. The available-screen size is a separate reading that can indicate reserved space. Screen coordinates can be negative or refer to another display. If screen.left and screen.top are unavailable, the diagram assumes screen origin (0, 0); that assumption may misplace a window on a multi-monitor desktop. No display permission is requested.

The visual viewport is drawn separately only when its size, offset or scale differs from the layout viewport (0.01 CSS-pixel tolerance). Root client dimensions help identify scrollbar or gutter space. Pinch zoom, mobile keyboards, browser UI, desktop zoom and emulation can affect the relationships. Device pixel ratio is reported separately and is not proof of physical display resolution.

Matching dimensions can occur in fullscreen, kiosk, emulated or automated setups. They do not identify automation by themselves. Values are self-reported and can be altered. No authenticity score is assigned.

Live readings refresh on resize and viewport changes, plus once per second while visible, to catch window movement. Freeze keeps the current snapshot for comparison or export. Measurements remain in this tab; downloads are local. No readings are uploaded.

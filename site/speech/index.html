How this check works

Voices are sampled for three seconds in the page and a fresh same-origin frame, including voiceschanged events and three final repeated reads. An empty list means no voices were returned during that window. “Local” and “remote” follow the API’s localService flag.

Test voice submits a short utterance using the selected voice and records start, end or error events, with a 15-second observation deadline. A completed utterance records the API lifecycle; it does not measure speaker output. A busy speech queue is left alone.

Readings stay in this tab. Save rendered HTML after Checks complete, or wait for #probe-complete[data-status="complete"]. The optional voice test updates the JSON separately.

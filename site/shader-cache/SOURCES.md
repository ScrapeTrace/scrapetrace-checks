# Shader-cache marker protocol v1

Maintained ScrapeTrace tool, added 7 November 2026. New source is MIT licensed with the Checks repository. Compilation workload and serial measurement architecture continue ScrapeTrace's independently authored ST—008 WebGL harness. Source facts and browser measurements are recorded separately under the workspace study `research/gpu-compilation-cache/experiments/context-marker-transfer/`.

Related work: https://github.com/Joe12387/ShaderGhost . Its public explanation covers warm/cold candidate pairs, destructive reads and refreshing records into fresh generations. On 7 November the owner supplied an analysis archive (SHA-256 27fb452df479b741acc20bfdef60b47f6c5bb6cb622b64144e8507201a6891ff). Its readable central routine was reviewed and tested privately; its accompanying simulated verification is not GPU evidence. The archive supplied no license notice. No implementation files or shader templates from that archive are included in Checks. Its automatic generation scan and parallel batched timing differ from this explicit namespace/bank protocol and serial timing.

## Result contract

Modes: plant/read. Namespace: 8–64 ASCII letters, digits, underscore or hyphen. Bank: integer 0–63. Marker: eight hex characters accepted only by planter. Reader has no expected-marker input. Versioned namespaces feed deterministic distinct shader workloads. Writer warms one candidate for each of 32 payload bits plus 32 public integrity-tag bits. Tag is the first 32 bits of SHA-256 over protocol/namespace/bank/marker. It detects corruption; it is not authentication, error correction or a confidence estimate.

Compile/link is timed through blocking LINK_STATUS. Triangle draw/pixel readback follows outside that interval. Six random calibration workloads are each measured cold and warm, plus an unrelated warmup. Median cold must be at least twice median warm, with at least 2 ms gap. These fixed rules produce an inconclusive outcome on weak separation, not a verdict that no cache exists. Exact tied candidates remain undecided and prevent record acceptance. Reader order is randomized per bit; full timing and draw records remain in exported JSON. The main-thread workload deadline is 20 seconds, checked between compilations; JavaScript cannot interrupt an already-blocked graphics driver call. Stop aborts between measurements and releases the context.

A plant verifies compilation completed, not retention. Recovery requires a separate read. Reads warm both candidates. Reuse another bank/namespace for another independent experiment. No automatic discovery, rewriting, telemetry, cookie/localStorage/IndexedDB payload or server result collector. Hosting sees normal URL requests. URL-carried marker values are random experimental payloads, not user IDs.

Successful marker transfer supports shared observable compilation state between those tested requests. A failure can reflect cache isolation, eviction, worker routing, environment differences, timing noise or partial writes. Physical cache layer, identity and vendor intent are not inferred. Public browser diagnostics use __PROBE_RESULT__, __PROBE_READY__, data-probe-ready and #probe-complete; all completed outcomes set completion, including errors and inconclusive/unsupported results.

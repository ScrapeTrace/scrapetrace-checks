What this check reads

Runs automatically. The simple check compares only navigator.userAgent. Full mode enumerates own and inherited string-named navigator properties, reads getters independently, and records errors. Nested objects are read to three levels and up to 100 properties or array entries per object, with truncation marked in the JSON. Symbol properties, internal state and method return values are outside this snapshot. It does not request permissions or call device APIs.

Frame means a new same-origin iframe. Workers include dedicated, shared and service workers. Unsupported, blocked and timed-out contexts are shown as unavailable, never counted as matching. Each context has a 10-second collection deadline. Matching readings are observations, not proof of an authentic browser. Dynamic values and browser privacy settings can affect comparisons.

Readings stay in this tab and local JSON downloads. Temporary workers, frame and service-worker registration are cleaned up after collection. The service worker uses a unique scope that does not control this page and has no fetch handler. Hosting requests fetch the code; no readings are uploaded.
